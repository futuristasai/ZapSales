Para que serve

Mostra a versão instalada no servidor e, quando há uma nova, o que muda nela — e atualiza com um clique, sem terminal. É uma tela da instalação, não da empresa: vale para todas as empresas do servidor, e fica em Administração › Configurar a instalação › Atualização.

Quem faz o trabalho é um programa pequeno que roda no servidor (o programa do servidor). A cada minuto ele conta a esta tela qual versão está instalada, qual é a última publicada e como está o backup; e é ele quem atende o botão. O sistema nunca manda comando ao servidor: ele só avisa “alguém pediu para atualizar”, e o programa decide o resto sozinho.

Como atualizar

  1. Abra o Painel. O cartão Versão mostra a instalada e, quando há uma nova, o selo Versão nova. Clique em Ver a atualização (ou no aviso “Nova versão · X.Y.Z” do rodapé).
  2. Leia o que muda. Os avisos “⚠️ Requer atenção” de todas as versões entre a sua e a nova ficam no topo, antes do botão.
  3. Clique em Atualizar agora. A tela mostra “Pedido enviado — esperando o servidor pegar”, com um relógio: o programa confere a cada minuto.
  4. Acompanhe os quatro passos: Guardando uma cópia de segurança dos seus dados → Baixando a versão nova → Atualizando o banco de dados → Conferindo, por 2 minutos, se a versão nova ficou de pé. O sistema sai do ar por alguns instantes no meio e volta sozinho; pode deixar a página aberta.
  5. No fim, a tela diz como terminou, e a linha entra no Histórico de atualizações, embaixo.
Atualizar tira o sistema do ar para todos, por alguns instantes.

A troca de versão reinicia o sistema para todas as empresas e usuários da instalação. Prefira um horário de pouco movimento. Cada pedido fica no Registro de ações (system.update_requested), com o desfecho (system.update_finished).

O que protege você

  • Cópia do banco antes de tudo. Se a cópia falhar, a atualização nem começa.
  • Volta automática. Depois de instalar, o programa confere por 2 minutos se a versão nova responde, se nada que estava funcionando piorou e se nenhum serviço reiniciou. Qualquer falha — e também qualquer erro no meio da instalação — faz o sistema voltar sozinho para a versão anterior: o código, a configuração e as imagens. O banco fica como está (a versão anterior funciona com ele); para desfazer também o banco, use a cópia feita antes, como explica Backup e restauração.
  • Só versões publicadas, e só para a frente. O botão leva sempre à última versão publicada (com número, como 1.3.0), nunca ao código em desenvolvimento, e nunca oferece voltar para uma versão mais antiga.
  • Uma atualização por vez. Dois cliques seguidos não disparam duas; um pedido que o servidor não atendeu em 15 minutos deixa de travar o botão.

Os estados da tela

TítuloO que significa e o que fazer
Você está na versão XÉ a mais recente. Não há nada a fazer.
Versão X disponívelOs avisos, o botão Atualizar agora e “O que muda”. Veja Como atualizar.
Pedido enviado — esperando o servidor pegarO programa confere a cada minuto: a tela parada nesse tempo é normal. Pode fechar a página; o pedido não se perde.
Atualizando para a versão XOs quatro passos, marcados conforme o programa conta.
A atualização para a versão X terminouDeu certo; o servidor confirma a versão na batida seguinte.
A atualização para a versão X não começouO servidor recusou antes de mexer em qualquer coisa — nada foi alterado. O motivo aparece em destaque (por exemplo, a versão nova ainda não terminou de ser publicada). Tentar de novo é seguro, e o botão volta.
A atualização para a versão X não deu certoDois desfechos. No normal, “a versão nova não ficou de pé, e eu voltei o sistema sozinho para a versão Y”: o sistema está no ar na versão anterior e os seus dados estão intactos; o motivo está em “Detalhes técnicos”. No raro, “não consegui voltar sozinho”: a tela mostra o comando para quem tem acesso ao servidor deixar tudo na versão que funcionava.
Não sei dizer como terminouO servidor ficou mais de 15 minutos sem dar notícia. Confira se o sistema está funcionando.
O programa do servidor está desligadoEle não dá notícia há mais de 5 minutos (ou nunca deu). O botão some e a tela mostra o comando que o liga: sudo systemctl enable --now zapsales-agente.timer. Se o servidor responder que a unidade não existe, a instalação é anterior ao programa: rode uma vez a atualização pelo terminal (curl -fsSL https://zapinstalador.futuristas.app/obter.sh | sudo bash), que ela instala o programa, e ele cuida das próximas.
Você está na versão X, numa instalação que acompanha o desenvolvimentoInstalação que anda pelo código em desenvolvimento e é atualizada sozinha a cada mudança aprovada. Não há botão: o programa só informa a versão.
“Não consegui checar se há versão nova”, “Ainda não há nenhuma versão publicada”, “Você está à frente da versão publicada”Casos de borda; a tela explica cada um.
