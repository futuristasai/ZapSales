titulo: O manual do usuário agora abre de dentro do sistema, pelo menu lateral
---

O menu lateral ganhou o link **Manual**, logo abaixo de **Configurações**. Ele abre, numa aba nova, o manual completo do ZapSales — cada tela, cada botão, com prints —, que agora vai **dentro da própria instalação**: funciona sem depender de site externo e sempre corresponde à versão que você instalou.

Só quem está logado lê o manual, de qualquer papel; quem não entrou é mandado para a tela de login, e os prints também ficam trancados. Nada precisa ser configurado: ao atualizar, o link já aparece. A imagem do sistema fica cerca de 32 MB maior, por causa dos prints.

Para o link caber sem fazer o menu rolar, o botão de recolher o menu passou a ser um ícone (as setas `«` e `»`) na mesma linha do **Manual**, em vez de uma linha só dele. Ele funciona como antes.
