titulo: Os Termos de uso deixam de chamar o ZapSales de software de código aberto
---

A página de **Termos de uso** dizia que o sistema é "um software de código aberto instalado e operado por" quem administra o servidor. Isso deixou de ser verdadeiro quando a licença do ZapSales mudou (o código continua público, mas sob a PolyForm Noncommercial, com licença comercial para uso em empresa), então a frase agora diz apenas que é "um software instalado e operado por" quem administra o servidor. Mudou nos quatro idiomas (português, inglês, espanhol e chinês). Nada mais na página mudou.
