O código do ZapSales continua público, mas deixou de ser MIT. A partir desta versão ele é distribuído sob a **PolyForm Noncommercial 1.0.0** (livre para estudar, testar e usar sem fins comerciais) e, para uso em empresa, sob uma **licença comercial de pagamento único**, sem assinatura, nas modalidades de **uso próprio** e de **revenda**. Nada muda dentro do sistema: telas, dados e configurações seguem como estavam.

As versões publicadas **antes** desta mudança continuam sob a licença MIT para quem as obteve; o último commit sob MIT é o marcado com a etiqueta `ultima-versao-mit`. O texto completo, em linguagem simples, está em `LICENSING.md`, e os avisos das bibliotecas de terceiros em `NOTICE`.

## Requer atenção

Se você usa o ZapSales **numa empresa** e vai atualizar para esta versão ou para uma posterior, é preciso ter a **licença comercial**: escreva para contato@futuristas.ai. Quem fica na versão anterior segue com os direitos da MIT sobre ela. Uso pessoal, de estudo ou de pesquisa, sem fins comerciais, continua livre.
