As páginas "Como usar este manual" e "Navegando pelo sistema" passaram a dizer onde fica o link **Manual**
(no rodapé do menu, logo abaixo de **Configurações**), que ele abre este manual numa aba nova e que o botão
de recolher o menu agora é só a setinha, na mesma linha. Nada muda no sistema; é só o texto do manual.
